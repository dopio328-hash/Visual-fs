# Aim Assist Menu (Fabric 1.21.4)

Правый Shift открывает меню с аим ассистом (вкл/выкл, дальность, плавность, FOV).

## Сборка
1. Положите рядом `gradlew` и папку `gradle/wrapper` из шаблона https://fabricmc.net/develop/template/ (или выполните `gradle wrapper` с установленным Gradle 8.12+).
2. `./gradlew build`
3. Готовый jar: `build/libs/aimassist-1.0.0.jar`. Положите в `mods/` вместе с Fabric API.

Использовать только в одиночной игре или на своих серверах.
